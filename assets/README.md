# Assets

This directory contains original public diagrams and, only after individual approval, sanitized screenshots.

## Diagrams

The diagrams are original visual explanations derived from the public architecture in this repository. They must not embed private source content, operational data, local paths, identifiers, or editor metadata.

## Screenshots

Screenshots are permitted only after explicit individual human approval. See [screenshots/README.md](screenshots/README.md).

No screenshot is included in the initial implementation.

## Asset review

Before publication, inspect both the rendered asset and its source for:

- hidden text or layers;
- metadata and comments;
- local filenames or paths;
- embedded images or source documents;
- real accounts, identifiers, URLs, data, or operational state;
- font, icon, and licensing constraints;
- sufficient contrast and readable labels.
