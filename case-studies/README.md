# Case Studies

These case studies explain how the architecture can operate in two different environments:

- [POW Water](pow-water.md): business operations across documents, meetings, data, tasks, and GIS.
- [PhotoVault](photovault.md): software engineering governed through a project repository, architectural decisions, experiments, and verification.

They are intentionally sanitized. They describe operating patterns, not current project state, canonical documents, internal decisions, private implementations, or complete system inventories.

No private repository content has been copied into these files. Names are used with explicit approval, while examples and workflow details remain generalized. Any future expansion must pass the disclosure rules in [SECURITY_AND_BOUNDARIES.md](../SECURITY_AND_BOUNDARIES.md).
