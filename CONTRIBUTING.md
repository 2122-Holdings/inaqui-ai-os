# Contributing

This repository documents public architectural patterns. Contributions must preserve the boundary between public explanation and private operations.

## Before contributing

- Use original prose, diagrams, and synthetic examples.
- Do not copy from a private repository, project workspace, conversation, transcript, source document, or dataset.
- Do not include real credentials, identifiers, local paths, private URLs, contacts, commercial details, operational state, or protected information.
- Treat every source repository and project environment as private by default.
- Confirm that you have authority to disclose any real organization, project, tool configuration, screenshot, or derived insight.
- Keep recommendations, decisions, actions, implementation, and validation distinct.
- Do not imply that model access grants organizational authority.

## Documentation changes

Explain patterns at the minimum level of detail needed. Prefer role names and source categories over real people, filenames, systems, or internal labels. Mark examples as synthetic when that may not be obvious.

Claims about current tools, providers, or automation should describe a bounded example rather than a universal OS capability.

## Assets

Screenshots require explicit individual human approval before inclusion. A general approval for a project, provider, or folder is not sufficient.

New diagrams must be original and must not embed source documents, private data, local paths, editor metadata, or unapproved fonts and assets.

## Review checklist

- [ ] The change is original public content.
- [ ] No private Git history or files were imported.
- [ ] Examples are synthetic or individually approved.
- [ ] Secrets, paths, URLs, IDs, contacts, and metadata were scanned.
- [ ] Private and commercially sensitive details were reviewed contextually.
- [ ] Source authority and freshness are represented accurately.
- [ ] Human and organizational authority boundaries remain explicit.
- [ ] Automation is described as scoped, not universal.
- [ ] Claims of completion include validation or evidence.
- [ ] Licensing and ownership questions are resolved before publication.

## Licensing

Licensing is intentionally undecided during the initial review stage. Do not assume permission to reuse, redistribute, or sublicense repository content until an explicit license is added.
